# John Mark Fuentes — Portfolio

Personal portfolio built with Astro and deployed to GitHub Pages. The page is styled with the selected ink blue, mist gray, coral, and white brand palette.

## Run locally

```sh
pnpm install
pnpm dev
```

Create a `.env` file based on `.env.example` when the companion API is deployed. The projects, tools, and social links are intentionally left unfilled for now.

## GitHub Pages

The GitHub Actions workflow builds and deploys the `main` branch. It configures the `/my-portfolio/` repository base path for `https://mcjh0n.github.io/my-portfolio/`. In the repository settings, enable Pages with **GitHub Actions** as the build and deployment source.

For the verified contact form and visit count, follow [the Worker setup guide](worker/README.md). Until configured, the contact form offers your email address and the count explains that setup is pending.
